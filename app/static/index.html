Add a generation workflow

Use an API JSON export, or an original ComfyUI PNG with saved prompt metadata. You can add several files together.

How do I get an API workflow?

In ComfyUI, enable developer/API export options in Settings, then export in API format. A normal canvas JSON is not executable API JSON. Original generated PNGs often contain the executable graph too; screenshots and re-saved images usually do not.

WildCat does not install custom nodes or download models. Import only workflows you trust.

What are the included guides for?

These are WildCat-authored enhancers based on linked official documentation, not official vendor prompts or benchmark-proven optimizations.

  • Z-Image Turbo: coherent scene descriptions, clear subject relationships, lighting, material detail, and literal text.
  • Krea 2: faithful natural-language expansion with purposeful medium, mood, and composition.
  • Qwen-Image 2.1: precise scene layout, requested typography, and task-specific editing or transparency wording.
  • Ideogram 4.5: design briefs, exact lettering, hierarchy, and targeted edit wording. This guide does not add an Ideogram API connection; use a compatible workflow or copy the prompts.
  • Cinematic / Editorial: the original generic WildCat starter guides; not tuned to a checkpoint.

The default minimum is still 300 words. Lower it, or set it to 0 for no forced minimum, when you want concise prompts. Sources and authorship are recorded inside each model guide.
